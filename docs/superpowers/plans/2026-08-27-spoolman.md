# Spoolman Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Run Spoolman on iserlohn at `https://spoolman.thisratis.gay`, authenticated for browsers and unauthenticated for LAN machine clients, with Moonraker reporting per-print filament usage.

**Architecture:** OpenWrt rewrites DNS answers so LAN clients reach Traefik with their true `10.0.0.x` addresses. Traefik gains a reusable `authentikBypassFrom` route option that emits a second, higher-priority router matching on `ClientIP()`. A `rat.services.spoolman` module wraps the nixpkgs module on SQLite. The Home Assistant integration is packaged locally, since it is not in nixpkgs and HACS is deliberately absent.

**Tech Stack:** NixOS (flake-parts), Traefik 3.7.10, dnsmasq on OpenWrt 25.12.5, Spoolman 0.23.1, Moonraker, Home Assistant.

Design doc: `docs/superpowers/specs/2026-08-27-spoolman-design.md`

- [ ] **Step 6: Write the hotplug script**

The WAN address is a DHCP lease. Without this, a lease change silently reverts LAN clients to appearing external, and the `ClientIP()` match in Task 2 starts failing with no obvious cause.

```bash
ssh root@openwrt.lan "cat > /etc/hotplug.d/iface/99-dnsmasq-alias <<'EOF'
#!/bin/sh
# The WAN address is a DHCP lease, but dnsmasq's alias rewrite hardcodes it.
# Without this the rewrite silently stops matching after a lease change, and
# LAN clients start reaching Traefik as the WAN address again.
[ \"\$ACTION\" = ifup ] || exit 0
[ \"\$INTERFACE\" = wan ] || exit 0

. /lib/functions/network.sh
network_get_ipaddr wanip wan || exit 0
[ -n \"\$wanip\" ] || exit 0

want=\"alias=\$wanip,10.0.0.10\"
[ \"\$(uci -q get dhcp.@dnsmasq[0].extraconftext)\" = \"\$want\" ] && exit 0

uci set dhcp.@dnsmasq[0].extraconftext=\"\$want\"
uci commit dhcp
/etc/init.d/dnsmasq restart
EOF
chmod +x /etc/hotplug.d/iface/99-dnsmasq-alias"
```

- [ ] **Step 7: Test the hotplug script without waiting for a lease change**

Run it directly with the environment a real event would supply:

```bash
ssh root@openwrt.lan 'ACTION=ifup INTERFACE=wan sh /etc/hotplug.d/iface/99-dnsmasq-alias; echo "exit=$?"; uci -q get dhcp.@dnsmasq[0].extraconftext'
```

Expected: `exit=0` and `alias=71.195.171.238,10.0.0.10`. Because the value already matches, the script should short-circuit and *not* restart dnsmasq — it is idempotent.

- [ ] **Step 8: Prove it actually repairs a wrong value**

```bash
ssh root@openwrt.lan "uci set dhcp.@dnsmasq[0].extraconftext='alias=192.0.2.1,10.0.0.10' && uci commit dhcp && ACTION=ifup INTERFACE=wan sh /etc/hotplug.d/iface/99-dnsmasq-alias; uci -q get dhcp.@dnsmasq[0].extraconftext"
```

Expected: back to `alias=71.195.171.238,10.0.0.10`. Re-run Step 4 to confirm resolution still works.

**Rollback:** `uci delete dhcp.@dnsmasq[0].extraconftext && uci commit dhcp && /etc/init.d/dnsmasq restart`, and `rm /etc/hotplug.d/iface/99-dnsmasq-alias`.

            type = types.listOf types.str;

- [ ] **Step 3: Hoist the rule builder so both routers share it**

Still in the same file, add to the top-level `let` block, after the `domainName` binding:

```nix
  # Shared by a route's main router and its Authentik-bypass twin, so the two
  # can never drift apart on host or path matching.
  routeRule = route: let
    hostRule =
      if route.subdomain != null
      then "Host(`${route.subdomain}.${domainName}`)"
      else "Host(`${domainName}`)";
    pathRule =
      if route.pathRegex != null
      then "&& PathRegexp(`${route.pathRegex}`)"
      else if route.path != null
      then "&& PathPrefix(`${route.path}`)"
      else "";
  in "${hostRule} ${pathRule}";
```

- [ ] **Step 4: Use the helper in the existing router, replacing the inline `let`**

Replace this block:

- [ ] **Step 5: Emit the bypass router**

In the `routers = lib.mkMerge [ ... ]` list, add a new element directly after the existing `lib.mapAttrs (...) cfg.routes` element and before the `{ dashboard = ...; }` element:

```nix
            (
              lib.concatMapAttrs (
                name: route:
                  if (route.enable && route.authentik && route.authentikBypassFrom != [])
                  then {
                    "${name}-bypass" =
                      {
                        # ClientIP takes one range per call, so several are ORed.
                        rule = "${routeRule route} && (${
                          lib.concatMapStringsSep " || " (range: "ClientIP(`${range}`)") route.authentikBypassFrom
                        })";
                        service = name;
                        entryPoints = ["websecure"];
                        tls = true;
                        middlewares =
                          (lib.optionals (route.stripPrefix && route.path != null) ["${name}-stripprefix"])
                          ++ route.extraMiddlewares;
                      }
                      # Traefik ranks equal-priority routers by rule length, and
                      # this rule is strictly longer than the one it shadows, so
                      # it already wins by default. An explicit priority on the
                      # route would break that, hence the +1.
                      // (lib.optionalAttrs (route.priority != null) {priority = route.priority + 1;});
                  }
                  else {}
              )
              cfg.routes
            )
```

### Task 3: `rat.services.spoolman` module

**Files:**
- Create: `modules/nixos/services/home/spoolman.nix`
- Modify: `modules/nixos/services/home/default.nix`

**Interfaces:**
- Consumes: `authentikBypassFrom` from Task 2; `config.rat.networking.lanRanges`.
- Produces: `rat.services.spoolman.{enable,subdomain,enableTraefik,authentik,lanBypass}`, and `config.links.spoolman` for Task 4 and the Home Assistant config.

**Design note — static user instead of `DynamicUser`.** The spec originally kept the nixpkgs module's `DynamicUser = true`. That interacts badly with impermanence: with `DynamicUser`, systemd's `StateDirectory` actually lives at `/var/lib/private/spoolman` with `/var/lib/spoolman` as a symlink, so persisting `/var/lib/spoolman` would persist a symlink and silently lose the database on reboot. A static user keeps the real path at `/var/lib/spoolman` and matches `printguard.nix`. Update the spec to match when this task lands.

- [ ] **Step 1: Write the module**

Create `modules/nixos/services/home/spoolman.nix`:

```nix
{
  config,
  lib,
  ...
}: let
  inherit (lib) modules options types;
  cfg = config.rat.services.spoolman;
  impermanenceCfg = config.rat.impermanence;

  stateDir = "/var/lib/spoolman";
in {
  options.rat.services.spoolman = {
    enable = options.mkEnableOption "Spoolman filament spool inventory";

    subdomain = options.mkOption {
      type = types.str;
      default = "spoolman";
      description = "The subdomain for Spoolman.";
    };

    enableTraefik = options.mkOption {
      type = types.bool;
      default = true;
      description = "Whether to enable Traefik reverse proxy for Spoolman.";
    };

    authentik = options.mkOption {
      type = types.bool;
      default = true;
      description = ''
        Put Spoolman behind Authentik forward auth. Spoolman has no
        authentication of its own, so this is the only thing between the public
        internet and a writable API.
      '';
    };

    lanBypass = options.mkOption {
      type = types.listOf types.str;
      default = config.rat.networking.lanRanges;
      description = ''
        Client ranges reaching Spoolman without Authentik. Moonraker and the
        slicer tooling send no auth headers and cannot answer a forward-auth
        challenge, so they need an unauthenticated path.

        Everything in these ranges gets read/write access to the whole
        inventory.
      '';
    };
  };

  config = modules.mkMerge [
    (modules.mkIf cfg.enable {
      links.spoolman.protocol = "http";

      services.spoolman = {
        enable = true;
        listen = config.links.spoolman.ipv4;
        port = config.links.spoolman.port;

        environment = {
          # SQLite is the default, and is what makes the two settings below
          # work at all -- Spoolman's backups are implemented only for it.
          SPOOLMAN_AUTOMATIC_BACKUP = "TRUE";
          SPOOLMAN_DIR_BACKUPS = "${stateDir}/backups";
          SPOOLMAN_METRICS_ENABLED = "TRUE";
        };
      };

      # The upstream module runs this under DynamicUser, which relocates the
      # state directory to /var/lib/private and leaves a symlink behind. That
      # symlink is what impermanence would persist, so the database would not
      # survive a reboot.
      systemd.services.spoolman.serviceConfig = {
        DynamicUser = lib.mkForce false;
        User = "spoolman";
        Group = "spoolman";
      };

      users.users.spoolman = {
        isSystemUser = true;
        group = "spoolman";
        home = stateDir;
      };
      users.groups.spoolman = {};
    })

    (modules.mkIf (cfg.enable && cfg.enableTraefik) {
      rat.services.traefik.routes.spoolman = {
        enable = true;
        inherit (cfg) subdomain authentik;
        authentikBypassFrom = cfg.lanBypass;
        serviceUrl = config.links.spoolman.url;
      };
    })

    (modules.mkIf (cfg.enable && impermanenceCfg.enable) {
      environment.persistence.${impermanenceCfg.persistDir} = {
        directories = [
          {
            directory = stateDir;
            user = "spoolman";
            group = "spoolman";
          }
        ];
      };
    })
  ];
}
```
